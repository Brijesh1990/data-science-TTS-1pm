# what is matplotlib in python ?
  **defintion** 
  1. A matplotlib is a low level graph plotting library in python that can be used to visualisation utitlity. 
  2. matplotlib was created by john D. Hunter. 
  3. Matplotlib is open source and we can use it without licence.
  4. matplotlib is mostly written in python , a few segements are written in c and javascript for plateform compatibility

   
  **how to used or install matplotlib**

  ```
   pip --version
   pip install --upgrade pip
   pip install matplotlib
   import matplotlib 
   print(matplotlib.__version__)
  ```

## what is Matplotlib Pyplot 

   **Pyplot**
   1. Most of all matplotlib utilities lies under the pyplot submodule.

   2. Pyplot are usually imported under the plt alias

     **examples**

     import matplotlib.pyplot as plt
